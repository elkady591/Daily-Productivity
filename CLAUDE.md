# Rules for working on this repo

## Pushing / الرفع
- Never push anything — not to `main`, not to any other branch — until the user explicitly says to push ("ارفع").
- Make the change, commit it locally, show the result, and wait. Push only after the user says "ارفع".
- When the user says push, push to `main` unless they name another branch.

- ممنوع رفع أي حاجة (على main أو أي فرع) غير لما المستخدم يقول "ارفع".
- اعمل التعديل و commit محلي وورّي النتيجة، واستنى الأمر.
